# Independent Cocos Plate diffraction-stack reconstruction

This is an independent Python reanalysis of Hutko et al. (2006),
[Nature 441, 333–336](https://doi.org/10.1038/nature04757), including later USGS
events through 2026-10-01. **It is a partial scientific reconstruction, not a
confirmed reproduction of the reported 100 km step.** Read
[the PDF report](report/report.pdf), [LaTeX source](report/report.tex), and
[panel ledger](report/panels.csv) before interpreting an image.

Four comparison sets are present: clearly marked published reference panels,
independently processed historical records, the expanded event population in
the same imaging region, and an expanded domain with illumination masks.
The three independent datasets have separate event-table/waveform supplements:

* [Historical](report/supplement-historical.pdf)
* [Expanded data, original region](report/supplement-modern_same.pdf)
* [Expanded data and region](report/supplement-expanded.pdf)

The [usage report](usage.pdf) distinguishes measured local computing from
unobserved remote inference usage and explicitly assumed dollar/power scenarios.

## Rebuild

Run all commands from this directory. Python, package caches, temporary files,
Matplotlib configuration, optional GitHub configuration, and local Git metadata
stay **inside this project**, without reassigning `HOME`.

```bash
bash scripts/bootstrap.sh
bash rebuild.sh --online       # download permitted archives, compute, plot, compile
# With the downloaded raw cache present:
bash rebuild.sh                # repeat computations and compile without acquisition
```

The bootstrap uses a small project-local Miniconda installation, a Python 3.11
environment, and pinned Python dependencies. It deliberately disables installer
registration in `~/.conda`. System TeX Live/pdflatex is used. The code was run on
Linux; all paths are relative to the project. Six download threads and up to
16 preprocessing processes are the defaults; migration uses three event workers
per independently processed dataset (up to nine workers); `bash rebuild.sh --workers 4`
reduces CPU use. No GPU is needed. NumPy/BLAS threading is fixed to one thread
per process. `logs/latest-run.json` and `logs/run-*.json` contain actual timings,
CPU seconds, sampled process-tree memory, and exit status.

To rebuild all numerical products from raw files, remove only the generated
`data/processed`, `data/images`, and `data/validation` directories and
`data/rays-*.npz` and `.cache/migration`, then run `bash rebuild.sh`. Keep `data/raw` and `data/catalog`.
The default preprocess cache also checks the processing code, configuration,
and receiver-correction file hashes. Migration checkpoints each event, keyed by input and implementation hashes, so
interrupted runs can resume. Successful downloads are immutable caches.
To retry a failed request, remove its adjacent `*.failed.json` file and rerun
acquisition. Raw MiniSEED is retained locally and deliberately excluded from Git;
the repository includes retrieval manifests, StationXML, processed numerical
traces, and generated data. From a Git checkout, use `--online` first.

Individual commands, in dependency order:

```bash
source scripts/env.sh
python scripts/acquire.py
python scripts/process.py --workers 16
python scripts/validate.py
python scripts/migrate.py
python scripts/experiments.py
python scripts/sensitivity.py historical modern_same expanded
python scripts/validate.py --points
python scripts/compare.py
python scripts/panels.py
python scripts/plot.py
python scripts/report.py
bash scripts/compile.sh
python scripts/usage.py
```

## What is implemented

Archive response removal to displacement; metadata-based sensor orientation;
optional receiver splitting correction; SH rotation; fixed filtering and SNR
screening; USGS moment-tensor radiation screening; ScS event source stacking;
water-level deconvolution; S normalization; symmetric phase mutes; independent
spherical upgoing-ray quadrature; S/ScS-reference three-dimensional Kirchhoff
migration; hitcount weighting; wider-region illumination masks; event bootstrap
double-array stacks; source-location perturbations; and synthetic operator checks.

No authors' code, processed waveform collection, simulation outputs, plotting
scripts, or separate figure assets are used. No published plot is digitized.
The article PDF is downloaded for reading and explicitly labelled reference
comparisons only. It is not a computational input. Numerical panels in `figures/`
are generated by `scripts/plot.py` from saved NPZ/JSON arrays. Conceptual slab
diagrams are labelled schematics. Natural Earth coastlines are context only.

## Scientific limitations

The complete numerical receiver splitting corrections were not recovered; the
correction file is empty and **no observed trace has this correction applied**.
The operator itself is implemented and tested. Current USGS tensors, catalog
magnitude revisions, automatic phase picks, and approximate historical station
membership produce a different accepted trace set. One printed event year is
inferred to be a typo: the 1999-08-30 entry matches the 1998-08-30 USGS event's
coordinates and depth. The ledger and supplements retain this assumption and
all processing failures.

The full-wave Scd triplication/reflectivity and 2.5-D finite-difference solver
are not implemented. Their supplementary panels are partial or unreproduced;
kinematic examples are not substituted for full-wave results. UT/UCB/CIT numerical
tomography coefficients are absent from the permitted written specifications.
Only the perturbation operator is implemented; those model panels and UT2
cross-sections are not reproduced. Nothing in the reconstruction proves a
folded slab or a 700 K temperature contrast.

## Saved data

* `data/catalog`: USGS queries/details and station query; `events.json` is the
  canonical event table (coordinates/depths always from USGS).
* `data/raw/EVENT`: requested station lists, MiniSEED, StationXML, retrieval
  manifests and failures. Only permitted waveform/metadata providers are used.
* `data/processed/EVENT.npz`: time in seconds from USGS origin, S-normalized
  processed/deconvolved traces, ScS source wavelet and its relative time, trace
  metadata, event record, and processing fingerprint. The adjacent audit JSON
  lists rejected records. No numerical trace is clipped.
* `data/images/DATASET.npz`: latitude/longitude/depth axes; mean and weighted
  amplitudes; valid trace and event counts. Order is
  `(variant, depth, latitude, longitude)` with variants stored in the file.
  No stack is a recovered absolute velocity perturbation.
* Profile NPZ files: CMB-scale distance, amplitudes and per-event sums.
  Double-array files include event-bootstrap intervals and event counts.
* `data/validation`: saved independent tests and explicitly simplified synthetics.
* `data/comparison.json`: numerical comparison to written published scales.
* `report/panels.csv`: a separate record for every identified panel and subpanel,
  including commands, assumptions, and unsuccessful attempts.

## GitHub publication

`bash scripts/publish.sh` creates a new public repository in the authenticated
account and pushes this project. It uses project-local Git metadata to coexist
with the workspace's protected `.git` directory. GitHub CLI authentication must
be available at `$PWD/.config/gh` or via an existing environment credential.
Authorized SSH access can push, but GitHub's API still requires authentication
to create a new repository. No credentials are committed.

The required research guidance is archived in `references/AGENTS.md` and
`references/academic-style.md`; these were the only files read from that GitHub
repository. See `references/README.md` for the scientific specification sources.

## Executed outcome

The documented `bash rebuild.sh` completed all 11 stages with exit status zero
on 13 October 2026 (the final log is dated 14 October in UTC). The final run
used 315.4 seconds of summed stage wall time, 733.2 CPU-seconds, and a
maximum sampled process-tree RSS of 3.109 GB. This run reused downloaded
waveforms and preprocessing/migration caches; it is not a fresh-install timing.
The full execution record is `logs/run-20261014T001400.json`.

The historical, same-region expanded, and wider expanded datasets contain
80 traces / 9 events, 531 traces / 34 events, and 913 traces / 36 events.
Both expanded datasets retain all historical traces. Resolution and source-location
sensitivity tests are repeated for every dataset geometry. The final report has
53 pages; `logs/deliverable-checks.json` records numerical/PDF checks.
Every generated numerical panel remains a partial scientific reproduction; the
implementation does not establish the published discontinuity step.

GitHub publication was attempted but authentication was absent; no remote
repository was created. After project-local GitHub authentication, run
`bash scripts/publish.sh`. It first tries authorized SSH, then authenticated
HTTPS without writing global Git configuration. `python scripts/package.py`
creates `deliverables.zip` with code, generated data, figures, and reports;
raw MiniSEED and environment/cache directories are excluded as above.
